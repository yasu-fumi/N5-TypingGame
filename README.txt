消灭讨厌鬼打字（ニガテ退治タイピング） - JLPT N5 タイピングゲーム
=====================================================================

■ 遊び方
  index.html をブラウザ（Microsoft Edge 推奨）で開くだけで遊べます。
  インストールは不要です。日本語入力（IME）はOFFにしてください。

■ フォルダの中身
  index.html   ゲーム本体。単語データ（N5 660語・中国語の意味つき）、
               敵23体、効果音、読み上げ、画面のデザインをすべて含む1ファイルです。
  README.txt   このファイル

■ 必要な環境
  ・インターネット接続：フォント（Google Fonts）の読み込みに使います。
    オフラインでも遊べますが、文字が標準フォントで表示されます。
  ・読み上げ音声：ブラウザに入っている日本語音声を使います。
    Edge では自然な音声（Nanami）が使われます。

■ セーブデータ
  掌握率・撃破記録・苦手な単語・設定は、ブラウザの中（localStorage）に保存されます。
  このフォルダには保存されません。ブラウザやPCを変えると記録は引き継がれません。
